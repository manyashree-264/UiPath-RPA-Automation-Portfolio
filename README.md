# UiPath RPA Automation Portfolio

Student-friendly UiPath projects demonstrating browser automation, Excel processing, Word document generation, PowerPoint creation, and integrated office automation.

## Projects

| Folder | Project |
|---|---|
| `01-Student-Excel-Management` | Student records, grades, filtering, and Excel reporting |
| `02-Invoice-Generator` | Planned Word invoice generation |
| `03-PowerPoint-Generator` | Planned presentation generation |
| `04-Browser-Automation` | Planned public-site information collection |
| `05-Integrated-Office-Automation` | Planned end-to-end workflow |

## Development status

All five projects contain sample inputs and Studio implementation guides. `Main.xaml` and `project.json` must be created and saved by UiPath Studio. No workflow is claimed as runtime-tested until it has executed successfully in Studio.
